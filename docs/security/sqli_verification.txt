การพิสูจน์ผล "SQL Injection" 114 รายการจาก OWASP ZAP (Full Scan แบบ login) — 4 พ.ย. 2569
วิธี: เปิด MariaDB general log แล้วส่งคำขอโจมตีทั้ง 114 รายการซ้ำ (payload เดียวกับ ZAP 56 แบบ)
ผล: คำสั่ง SQL ที่ฐานข้อมูลได้รับ (Prepare/Query) 1962 คำสั่ง — มี payload ของการโจมตีอยู่ในโครงสร้าง SQL: 0 คำสั่ง
     payload ปรากฏเฉพาะในขั้น Execute (ค่าพารามิเตอร์ที่ bind แล้ว จัดเก็บเป็นข้อความธรรมดา) — Execute ทั้งหมด 1957 ครั้ง
สรุป: ไม่สามารถแทรกคำสั่ง SQL ได้ — ทั้ง 114 รายการเป็น false positive ของการตรวจแบบเปรียบเทียบหน้าเว็บ (หน้าเว็บมี CSRF token / เวลา ที่เปลี่ยนทุกครั้ง)
