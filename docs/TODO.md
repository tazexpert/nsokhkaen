# รายการที่ต้องทำ (ยังไม่เริ่ม)

## 1. ระบบตัวชี้วัด (KPI) — ระบบใหม่

ขอเมื่อ 20 พ.ย. 2569 · ต้นแบบจากไฟล์ "รายละเอียดตัวชี้วัดตามคำรับรองการปฏิบัติราชการของสำนักงานสถิติจังหวัด รอบที่ 2/2569"
(ไฟล์ PDF ที่ผู้ใช้แนบในแชต — ไม่ได้เก็บใน repo · สรุปโครงสร้างไว้ด้านล่าง)

### สิทธิ์ (role)
| role | ทำอะไรได้ |
|---|---|
| ผู้ปฏิบัติ | บันทึกความก้าวหน้า และแนบหลักฐานการปฏิบัติงาน (เฉพาะตัวชี้วัด/กิจกรรมที่ได้รับมอบ) |
| ผู้ควบคุมตัวชี้วัด | สร้าง/แก้ไขตัวชี้วัด มอบผู้ปฏิบัติ ดูความก้าวหน้าตัวชี้วัด |
| ผู้ดูแลระบบ | ทำได้ทุกอย่าง |

### ข้อมูลตัวชี้วัด
- ปีงบประมาณ
- รอบที่ — รอบที่ 1 = 1 ต.ค. – 31 มี.ค. · รอบที่ 2 = 1 เม.ย. – 30 ก.ย.
- ชื่อตัวชี้วัด (มีตัวชี้วัดย่อยได้ เช่น 1.1, 1.2 — ในไฟล์: ข้อ 1 สค. 20% แยก 1.1 / 1.2 ข้อละ 10%)
- หน่วยวัด (เช่น คะแนน)
- น้ำหนัก (ร้อยละ — รวมทั้งรอบ 100%)
- คำอธิบาย (ข้อความยาว มีหัวข้อย่อย/รายการ)
- กลุ่มงานที่รับผิดชอบ (core_work_groups)
- เกณฑ์การให้คะแนน — ตาราง: **ระดับที่ · ประเด็นการประเมิน · หลักฐาน/เอกสารประกอบ · คะแนนที่ได้**
  - 1 ระดับมีหลักฐานได้หลายข้อ แต่ละข้อมีเงื่อนไขคะแนนของตัวเอง (เช่น ระดับ 4: ข้อ 1 = 1 คะแนน, ข้อ 2 = 2 คะแนน, ข้อ 3 = 1 คะแนน)
  - เงื่อนไขคะแนนแบบรายเดือน (เช่น ส่งรายงานเดือน พ.ค. ภายใน 2 มิ.ย. ได้ 0.5 คะแนน)
- กิจกรรมในแต่ละระดับคะแนน — มอบผู้ปฏิบัติ **รายกิจกรรม** ได้ · ระบุวันที่ต้องส่งได้
- หมายเหตุ (เช่น วิธีส่งหลักฐาน กำหนดส่งรวม "ภายในวันศุกร์ที่ 11 กันยายน 2569")
- ผู้ปฏิบัติ — ช่องเลือกแบบเดียวกับระบบปฏิทิน (event_form: ทุกคน / ข้าราชการ / พนักงาน / ตามกลุ่มงาน / รายคน · เรียงด้วย sort_staff())
- ผู้ควบคุมตัวชี้วัด (ในไฟล์: "ผู้กำกับดูแลตัวชี้วัด" + "ผู้จัดเก็บข้อมูล" ชื่อ/ตำแหน่ง/เบอร์ติดต่อ)

### การใช้งาน
- ผู้ปฏิบัติ: บันทึกความก้าวหน้า + แนบไฟล์หลักฐาน (pdf / xlsx / docx / รูป · ลิงก์ URL / QR Code)
- ผู้ควบคุมตัวชี้วัด: สร้างตัวชี้วัด ดูภาพรวมความก้าวหน้า (คะแนนที่ได้เทียบน้ำหนัก ต่อรอบ)
- แจ้งเตือน: กิจกรรมที่ระบุวันที่ต้องส่ง → เตือนผู้ปฏิบัติ (และผู้ควบคุม) **ก่อนกำหนด 15 วัน** (ระบบแจ้งเตือนกลางแบบระบบอื่น)

### ตามแนวทางของโครงการ (CLAUDE.md)
- โมดูลใหม่ `modules/kpi/` (module.php roles/menu, header.php ใส่ `mod-theme theme-kpi` + กำหนดสีใน app.css, การ์ดหน้าแรก)
- ภาพรวม: การ์ด `.stat-card` + กราฟ/แถบความก้าวหน้ามี animation (data-reveal / reveal-item / bar-fill · ปิดตอนพิมพ์และ prefers-reduced-motion)
- ตาราง: migration ใน `database/migrations/` (รันซ้ำได้) + `database/schema.sql` + `python3 tools/build_migrate_all.py` + ตารางใน `docs/MIGRATION.md`
  · เซิร์ฟเวอร์จริงไม่มีสิทธิ์ ALTER TABLE — ออกแบบให้ CREATE TABLE ครบตั้งแต่แรก
- ไฟล์แนบเก็บนอก URL ตรง (แบบ uploads/shares + share_file.php: ตรวจสิทธิ์ก่อนส่งไฟล์) · มี .htaccess และ web.config (IIS)
- PHP 8.0 (ห้ามฟีเจอร์ 8.1+) · ลิงก์ภายในไม่ใส่ .php · ข้อความภาษาไทย
