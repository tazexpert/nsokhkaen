# ระบบบริหารจัดการ สำนักงานสถิติจังหวัดขอนแก่น

ระบบเว็บแบบรวมศูนย์ (PHP + MySQL) — **login เดียว ใช้ได้ทุกระบบ** และกำหนดสิทธิ์แยกรายระบบได้
ออกแบบให้เพิ่มระบบใหม่ได้ในอนาคตโดยไม่ต้องแก้โค้ดส่วนกลาง

| ระบบ | โฟลเดอร์ | ตาราง | บทบาท (ต่ำ → สูง) |
|---|---|---|---|
| ระบบกลาง (ผู้ใช้ สิทธิ์ ตั้งค่า) | `core/`, `admin/` | `core_*` | ผู้ดูแลระบบกลาง (superadmin) |
| ระบบบริหารจัดการวัสดุและครุภัณฑ์ | `modules/inventory/` | `inv_*` | เจ้าหน้าที่ · ผู้ดูแลระบบวัสดุและครุภัณฑ์ |
| ระบบศูนย์ดิจิทัลชุมชน | `modules/digitalcc/` | `dcc_*` | ผู้ตรวจเยี่ยม · เจ้าหน้าที่ · ผู้ดูแลระบบศูนย์ฯ |

## ความสามารถ

**ระบบกลาง**
- เข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่าน หรือ **PIN 6 หลัก** (เหมาะกับหน้าสแกน QR บนมือถือ)
- ผู้ดูแลระบบกลาง: เพิ่ม/แก้ไข/ปิดบัญชีผู้ใช้ กำหนดสิทธิ์รายระบบ ตั้งชื่อหน่วยงานและ URL ของระบบ ดูบันทึกการใช้งาน
- บัญชีของฉัน: แก้ข้อมูลส่วนตัว/ตำแหน่ง เปลี่ยนรหัสผ่าน ตั้ง/ลบ PIN
- ผู้ใช้แต่ละคนมี **กลุ่มงาน** (กลุ่มปฏิบัติการสถิติและดิจิทัล / กลุ่มวิชาการสถิติและวางแผน / กลุ่มขับเคลื่อนงานด้านดิจิทัล)
- รหัสผ่านอย่างน้อย 6 ตัวอักษร · รายชื่อผู้ใช้เรียงตามชื่อผู้ใช้ (ตัวเลขก่อนตัวอักษร)
- หน้าหลักแสดงเฉพาะระบบที่ผู้ใช้มีสิทธิ์ · **เมนูด้านบน** รวมทุกระบบ + แถบเมนูย่อยของระบบที่เปิดอยู่
- **การแจ้งเตือน (กระดิ่ง)** เปิดให้เห็นทันทีหลัง login — แต่ละระบบเพิ่มรายการแจ้งเตือนของตัวเองได้

**ระบบบริหารจัดการวัสดุและครุภัณฑ์** (ย้ายมาจาก nsokhkaen_inventory)
- สแกน QR Code ด้วยกล้องมือถือเพื่อเบิกวัสดุ (ยืนยันตัวด้วย PIN) สะสมหลายรายการเป็นใบเบิกเดียว
- ใบเบิกเลขที่ `เลขรัน/ปี พ.ศ.` พิมพ์ตามแบบฟอร์มสำนักงาน อนุมัติ/ยกเลิก (คืนสต๊อก)
- จัดการวัสดุ รับเข้าสต๊อก แนบรูป นำเข้า Excel 3 รูปแบบ พิมพ์ QR/แคตตาล็อก
- รายงานการเบิก มูลค่า และวัสดุที่ควรจัดหา
- **ทะเบียนครุภัณฑ์**: เลขครุภัณฑ์ ประเภท ยี่ห้อ รุ่น ปีงบ อายุ หมายเหตุ · สภาพ ใช้งานตามปกติ/เสียรอซ่อม/รอจำหน่าย
  · สรุปตามประเภท · นำเข้า/ส่งออก CSV ตามรูปแบบรายงานครุภัณฑ์ของสำนักงาน
- **ยืม-คืนครุภัณฑ์**: ขอยืม → ผู้ดูแลอนุมัติ/ส่งมอบ → รับคืน (บันทึกสภาพหลังคืน) · แสดงชื่อผู้ยืมในรายการครุภัณฑ์
  · พิมพ์ "บันทึกข้อความ ขออนุมัติยืมพัสดุ" ตามแบบฟอร์มสำนักงาน · แจ้งเตือนคำขอใหม่/เกินกำหนดคืน
- แจ้งเตือนผู้ดูแล: คำขอยืม ใบเบิกใหม่ และวัสดุที่ถูกเบิกล่าสุดซึ่งหมด หรือเหลือไม่เกินจำนวนขั้นต่ำ

**ระบบศูนย์ดิจิทัลชุมชน**
- ข้อมูลศูนย์ 46 แห่ง พิกัด ภาพ ผู้ดูแล กิจกรรม ค้นหาพิกัดอัตโนมัติ
- แบบฟอร์มตรวจเยี่ยมศูนย์ (ตรวจได้หลายครั้ง พิมพ์ได้) อัปเดตข้อมูลศูนย์/พิกัด GPS หน้างาน
- เว็บไซต์สาธารณะ: `modules/digitalcc/public/` (หรือ `digital.html` ที่ root)

## ติดตั้งใหม่

ต้องการ PHP 8.1+ (`pdo_mysql`, `gd`, `zip`, `simplexml`) และ MySQL 5.7+ / MariaDB 10.3+ — ไม่ต้องใช้ Composer

```bash
git clone https://github.com/tazexpert/nsokhkaen.git
mysql -u root -p < nsokhkaen/database/schema.sql
mysql -u root -p < nsokhkaen/database/seed.sql
```

สร้างไฟล์ `config.local.php` (ค่าการเชื่อมต่อฐานข้อมูล — ไม่ถูกเก็บใน git):

```php
<?php
define('DB_HOST', 'localhost');
define('DB_NAME', 'nsokhkaen');
define('DB_USER', 'root');
define('DB_PASS', '');
```

ให้เว็บเซิร์ฟเวอร์เขียนโฟลเดอร์ `uploads/` และ `libs/phpqrcode/cache/` ได้ แล้วเปิด `http://localhost/nsokhkaen/`
เข้าสู่ระบบด้วย **admin / admin1234** แล้ว:

1. เปลี่ยนรหัสผ่านที่ **บัญชีของฉัน**
2. ตั้ง **URL ของระบบ** ที่ ผู้ดูแลระบบกลาง → ตั้งค่าระบบ ให้เป็นที่อยู่ที่มือถือเข้าถึงได้ (เช่น `http://192.168.1.50/nsokhkaen/`) — ใช้ใน QR Code
3. เพิ่มผู้ใช้และกำหนดสิทธิ์ที่ **ผู้ใช้งานและสิทธิ์**

> ระบบตรวจ path ของเว็บให้อัตโนมัติ (ติดตั้งในโฟลเดอร์ชื่ออื่นได้) ค่า URL ใช้เฉพาะลิงก์ที่เปิดจากอุปกรณ์อื่น เช่น QR Code
> ใช้ HTTPS ถ้าต้องการใช้ปุ่ม "ตำแหน่ง GPS ปัจจุบัน" บนมือถือในแบบฟอร์มตรวจเยี่ยม
